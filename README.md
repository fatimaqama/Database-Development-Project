Database Development Project

Microsoft Access | BTEC IT Coursework

Project Overview

This project involved designing and developing a business-related database using Microsoft Access as part of my BTEC IT coursework. The database was created to organise business information, retrieve relevant data and present useful information through queries and reports.

The project helped me develop practical experience in database design, data management and reporting.

Key Features

Database Design: Structured information to support the requirements of a business-related scenario.

Queries: Created queries to retrieve, filter and organise data.

Report Generation: Developed reports to present information clearly and support business reporting.

Data Management: Organised fictional business data to make information easier to access and analyse.

Queries and Reports

The project included reports covering the following areas:

Daily Order Summary

Customers with No Orders in the Last Three Months

Low Stock Products

Customer Orders

Sales Summary by Category

Products by Category

These reports demonstrate how database queries can be used to retrieve relevant information and present it in a useful format.
